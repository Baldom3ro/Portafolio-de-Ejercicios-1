Interceptor de Peticiones

Manejo de Estado Offline

Este ejercicio implementa un fallback offline: cuando una petición falla por falta de conexión, el Service Worker sirve la página offline.html precargada en el evento install.

Paso 1

install

Precarga offline.html junto con el App Shell.

Paso 2

activate

Limpia cachés antiguas y toma control de los clientes.

Paso 3

fetch + catch

Si la red falla, sirve la vista de fallback offline.

Fallback Personalizado

Vista Offline

La página offline.html es una vista independiente que se precarga durante el install y se sirve cuando el interceptor detecta que la red está inaccesible.

Estado de conexión

Instrucciones de validación manual en DevTools

  1. Abre la aplicación en un servidor local (HTTP/HTTPS).
  2. Registra el Service Worker y espera a que el caché ejercicio5-cache-v1 se complete.
  3. Ve a Application > Cache Storage y comprueba que offline.html esté precargado.
  4. En la pestaña Network, marca Offline.
  5. Recarga la página o navega a un recurso no cacheado y verifica que aparezca la pantalla de fallback.
  6. Desactiva Offline y vuelve a conectar para confirmar que la app se recupera.
